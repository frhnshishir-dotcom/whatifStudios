# Before M1 and M2 (2026-11-27)

These numbers come from a cloud container: Node 22, headless Chromium on SwiftShader (software GL), 1280×800, the
Canvas 2D presenter. They are **not laptop numbers**. They were produced by `npm run bench:server` and
`npm run bench:continent`.

Saving takes 2.7–4.2 ms (56–145 KB). Loading (server start with a save) takes 1.35–1.48 s.

The Phase 0 audit run of the same spread case (unseeded bots) measured a mean of 51.6 ms and a maximum of 2,833 ms.
The stalls depend on when bots cross into regions that are not cached. In both runs they are all region generation
on the main thread.
